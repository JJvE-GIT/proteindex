# Proteindex

Dagelijks bijgewerkt overzicht van kwark, skyr en eiwitrijke yoghurt, gerangschikt op prijs per 100 g eiwit.

- `data/eiwit.json`: eiwitwaarden per productlijn, met bron. Nieuw product toevoegen doe je hier.
- `scripts/build.py`: koppelt prijzen aan eiwitwaarden.
- `docs/`: de website.
- `.github/workflows/update.yml`: dagelijkse update.

Prijsdata: [Checkjebon](https://github.com/supermarkt/checkjebon) (MIT).
